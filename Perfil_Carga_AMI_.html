Datos de la SED y evaluación preliminar

Origen automático: se identificaron dos hojas de medición, una por circuito BT.
Ingrese la capacidad nominal para determinar automáticamente el tipo de SED y el calibre NH de referencia.

Lectura de dos hojas: el archivo Excel puede contener las hojas «Circuito BT 1» y «Circuito BT 2» (también reconoce «BD» como primera hoja si se agrega una segunda). Cada hoja debe incluir Fecha, Tensión F1/F2/F3 y Corriente L1/L2/L3. Los horarios deben coincidir. No se suman máximos de fechas diferentes.
Evaluación normativa: NTCSD Chile, art. 3-1: ±7,5 % para redes de densidad alta/media y ±10 % para baja/muy baja/extremadamente baja; al menos 95 % del tiempo con promedios de 10 minutos en siete días. Las lecturas de la planilla son orientativas y no constituyen certificación. Fuente CNE.

Criterio de clasificación: hasta 25 kVA se considera SED bifásica/monofásica para la interfaz; sobre 25 kVA, trifásica. El plano 30-10-A4 denomina sus variantes de BT monofásica bifilar/trifilar y trifásica. Para 25 kVA se utiliza NH 100 A; para 125 kVA, NH 200 A (1 circuito BT) o NH 100 A (2 circuitos BT). Estas tres asignaciones siguen el criterio indicado por el usuario, ya que el plano no contiene las filas correspondientes. Los demás calibres son referencias del plano. Ninguno acredita por sí solo el fusible instalado. Se considera 1 kW por cliente de manera referencial. Para 2 circuitos, incorpore las hojas «Circuito BT 1» y «Circuito BT 2», con las mismas fechas y horas, tensión y corriente de cada fase. La holgura total se calcula solo con intervalos simultáneos.
